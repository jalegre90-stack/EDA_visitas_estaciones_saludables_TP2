# EDA - Visitas a Estaciones Saludables (CABA)

Actividad Individual 2: análisis exploratorio de datos (EDA) básico sobre el dataset
**Visitas a Estaciones Saludables** de la Ciudad Autónoma de Buenos Aires.

## Dataset

- Fuente: [Portal de Datos Abiertos de la Ciudad de Buenos Aires](https://data.buenosaires.gob.ar/dataset/visitas-estaciones-saludables/resource/5ff36682-e501-49d0-96f9-0cfd60893333)
- Archivo local: `visitas_estaciones_saludables.csv`
- Variables: `anio`, `sexo`, `cantidad_personas`, `grupo_edad`, `lugar_residencia`

## Contenido

- `EDA_visitas_estaciones_saludables_TP2_Final.ipynb`: notebook con el EDA básico
  (estadística descriptiva, tipos de variables, relaciones entre variables y gráficos).

## Cómo correrlo

1. Cloná o descargá este repositorio.
2. Instalá las dependencias: `pip install pandas numpy matplotlib seaborn scipy`
3. Abrí `EDA_visitas_estaciones_saludables_TP2_Final.ipynb` con Jupyter Notebook / JupyterLab
   y ejecutá las celdas en orden (`Kernel > Restart & Run All`).
